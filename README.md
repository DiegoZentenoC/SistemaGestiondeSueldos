# 💼 Sistema de Gestión de Sueldos

Aplicación de escritorio desarrollada en **C# (.NET Framework)** y **SQL Server**, orientada a la administración de empleados y al cálculo automatizado de remuneraciones. Este proyecto fue desarrollado como parte de mi formación en la carrera de **Técnico en Programación y Análisis de Sistemas**.

---

## 📋 Descripción

El sistema permite gestionar la información de los trabajadores y calcular sus remuneraciones de manera sencilla y eficiente, almacenando todos los datos en una base de datos SQL Server.

El proyecto fue diseñado aplicando principios de programación orientada a objetos, manejo de bases de datos relacionales y una interfaz gráfica desarrollada con Windows Forms.

---

## 🚀 Tecnologías utilizadas

* C#
* .NET Framework (Windows Forms)
* SQL Server
* SQL Server Management Studio (SSMS)
* ADO.NET

---

## ✨ Funcionalidades

* Registro de empleados.
* Consulta de empleados por RUT.
* Actualización de información.
* Eliminación de registros.
* Cálculo de sueldo bruto.
* Cálculo de descuentos previsionales.
* Cálculo de sueldo líquido.
* Gestión de AFP y sistema de salud.
* Conexión a base de datos SQL Server.

---

La aplicación utiliza **SQL Server** para almacenar la información de los empleados.
